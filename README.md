# Правда или Дедлайн

Бизнес-игра на креатив про звёзд, бренды и поп-культуру. Играть: https://omarumarov1-png.github.io/pravda-ili-dedlain/

- От одного игрока и больше, на одном устройстве; игроков можно добавлять и убирать прямо во время игры.
- 38 карточек: **ДЕДЛАЙН** (бизнес-кейс со звездой, быстрый ответ даёт двойной бонус скорости) и **ПРАВДА** (честные вопросы о знаменитостях и деньгах).
- На каждую карточку 4 готовых варианта (от «сильного хода» до «осторожно») или свой ответ, который оценивается выше.
- Таймер на ответ (20–60 секунд), автоматическая оценка креативности с разбором очков, таблица «Квартальный KPI», выход из игры в любой момент.

Один файл `index.html`, без сборки и зависимостей (шрифты подгружаются с Google Fonts).
Ситуации со знаменитостями — вымышленные гипотезы для игры, а не описания реальных событий.
