# Правда или Дедлайн

Бизнес-игра и психотест для подростков: звёзды, блогеры, школьные стартапы и очень странные бизнес-кейсы. Играть: https://omarumarov1-png.github.io/pravda-ili-dedlain/

- От одного игрока и больше, на одном устройстве; игроков можно добавлять и убирать прямо во время игры.
- Два режима: **Игра на очки** (таймер, оценка креативности) и **Психотест** (без таймера и очков).
- 104 карточки: **ДЕДЛАЙН** (смешной бизнес-кейс, быстрый ответ даёт двойной бонус скорости) и **ПРАВДА** (честные вопросы о вас и деньгах).
- Каждый ответ выдаёт бизнес-психотип: Визионер, Акула, Шоумен, Дипломат, Перестраховщик, Хаос-менеджер. В конце — психотип каждого игрока с раскладкой, ачивки (Спидраннер, Режим NPC, Хамелеон…) и «химия команды»: кто с кем лучше откроет бизнес.
- На каждую карточку 4 готовых варианта (от «сильного хода» до «осторожно») или свой ответ, который оценивается выше.
- Таймер на ответ (20–60 секунд), автоматическая оценка креативности с разбором очков, таблица «Квартальный KPI», выход из игры в любой момент.

Один файл `index.html`, без сборки и зависимостей (шрифты подгружаются с Google Fonts).
Ситуации со знаменитостями — вымышленные гипотезы для игры, а не описания реальных событий.
